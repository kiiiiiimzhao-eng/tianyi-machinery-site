- **裸域 522 诊断**：用户反馈 `tianyimachine.com` 直接打开报 Cloudflare 522。经 nslookup 与 curl 实测：
  - apex DNS 已解析到 Cloudflare IP（104.21.34.89 等）；
  - `https://www.tianyimachine.com/` 返回 200；`https://tianyimachine.com/` 超时（522）。
  - 根因：apex 域名未在 Cloudflare Pages 项目里绑定为 Custom Domain，Cloudflare 收到请求但找不到对应 Pages 项目，因此报 522；`_redirects` 里的 apex→www 301 规则因未进入 Pages 而未生效。
  - 修复：到 Cloudflare Pages 后台把 `tianyimachine.com` 加为 Custom Domain（与 www 并列），之后裸域即可正常触发重定向到 www。已更新 MEMORY.md 长期备忘。
  - 用户已在 Pages 自定义域面板看到 `tianyimachine.com` 状态为「停用」，提示添加 CNAME 指向 `tianyi-machinery-site.pages.dev`。修复步骤：1) Cloudflare DNS 中删除/停用 apex 现有 A/AAAA 记录；2) 添加 `@`（根域）CNAME → `tianyi-machinery-site.pages.dev`，**代理状态设为 DNS 专用（灰云）**；3) 返回 Pages 面板点击「检查 DNS 记录」；4) 等待验证完成（提示最多 24 小时），状态变为「活动」后裸域即可 301 到 www。
  - DNS 记录添加后出现感叹号提示（根域 CNAME + 与 www 指向同一 target IP 的冲突提示），属 Cloudflare 正常提示；保持灰云、忽略警告，直接回 Pages 验证即可。
