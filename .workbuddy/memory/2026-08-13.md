## 网站诊断与优化

### 裸域 DNS 问题诊断
- 用户反馈 `tianyimachine.com`（不带 www）打不开，`www.tianyimachine.com` 正常。
- **根因确认**：域名 DNS 托管在 `ns.wuhan.net.cn`（非 Cloudflare 名字服务器），www 有 CNAME 指向 Cloudflare，但**裸域缺少 A 记录**。
- Cloudflare Pages Custom domains 已显示两个域都"活动+SSL已启用"——说明 Cloudflare 这边没问题，问题在上游 DNS 缺记录。
- **修复方案**：在域名 DNS 管理后台添加 A 记录：类型=A，主机=@，值=192.0.2.1（Cloudflare Pages 官方 apex IP）。

### Favicon 修复（灰色地球图标 → 公司 Logo）
- 根因：全站 HTML 之前**没有 `<link rel="icon">` 标签**，浏览器只能显示默认灰色地球图标。
- 方案：给全部 25 个公开页面（排除 audit/）的 `<head>` 加入：
  `<link rel="icon" type="image/png" href="/images/logo-200.png">`
- 用**根相对路径** `/images/logo-200.png`（200x200 正方形 PNG），从任意页面深度（首页/products//blog/）都能正确加载。
- logo 素材确认均为正方形：logo.png(800)、logo-200.png(200)、logo-160.png(160)、logo-original.png(80)。选 200px 兼顾清晰度与体积(13.6KB)。
