## 修复首页 Chlor-Alkali 项目卡片图片 404
- **问题**：首页 `index.html` 项目卡片"Chlor-Alkali Chemical Bulk Material Conveying System"顶部图片不显示（空白灰色）。
- **根因**：HTML 中 `img src="images/projects/chlor alkali/main.JPG"` 使用大写扩展名，而实际文件为 `main.jpg`；Cloudflare Pages 运行 Linux，文件名大小写敏感，导致 404。
- **修复**：将 3 个 HTML 文件中的 `main.JPG` 统一改为 `main.jpg`：
  - `index.html` 第 791 行（首页项目卡片）
  - `blog/chlor-alkali-conveying-system.html` 第 257 行（英文博客配图）
  - `ru/blog/chlor-alkali-conveying-system.html` 第 259 行（俄文博客配图）
- **验证**：全站 HTML 中已无 `main.JPG` 引用，与磁盘实际文件名 `main.jpg` 一致。

## 修复 Yandex/Bing 搜索结果角标（favicon）不显示
- **问题**：公司 logo 在 Yandex、Bing 搜索结果"角标"位置不显示（浏览器标签页其实有 PNG 图标，但 SERP 角标需要根目录 favicon）。
- **根因**：全站 HTML 仅声明 `<link rel="icon" type="image/png" href="/images/logo-200.png">`，站点根目录**缺少 `/favicon.ico`**；Yandex/Bing 在搜索结果中优先抓取根目录 favicon.ico，缺失则不显示角标。
- **修复**：
  1. 用 Pillow 由 `images/logo-200.png` 生成多尺寸 `favicon.ico`（含 16/32/48/64/128 共 5 档，约 34KB）置于站点根目录 `tianyi-site/favicon.ico`（部署后为 `https://www.tianyimachine.com/favicon.ico`）。
  2. 批量在全部 50 个线上 HTML 页面（EN+RU）的 `<head>` 增加 `<link rel="icon" href="/favicon.ico">`（保留原 PNG 链接），脚本幂等更新。
  3. 校验 `robots.txt` 为 `Allow: /`，未屏蔽 favicon 与图片目录。
  4. `./audit/` 下 3 个内部报告页未加（非线上页，无需）。
- **说明**：搜索引擎需重新抓取才会更新 SERP 角标；Push 后建议到 Bing Webmaster Tools / Yandex Webmaster 触发重新索引或等待自然抓取。
- 待用户 GitHub Desktop Commit + Push 上线。
