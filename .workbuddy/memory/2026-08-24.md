## 排查 Yandex/Bing 角标仍显示灰色地球
- 用户反馈搜索引擎结果角标仍是默认灰色地球（即"无 favicon"占位），怀疑部署有问题。
- 实测结论：**favicon 部署完全正常，不是文件/代码问题**。
  - 线上 `https://www.tianyimachine.com/favicon.ico` 返回 HTTP 200，Content-Type `image/vnd.microsoft.icon`（合法 ICO）。
  - 线上首页 `<head>` 含 `<link rel="icon" href="/favicon.ico">` + PNG 回退，声明正确。
  - 浏览器标签页能看到 logo（说明 PNG/ICO 均有效）。
- 根因：Yandex、Bing 会缓存站点 favicon，仅在重新抓取首页时才刷新；它们上次抓取时 favicon 尚未存在（或早于 2026-08-19 加入），缓存了"无图标"默认地球，至今未重新抓取更新。
- 解决方向（无需改代码）：在两个站长平台触发**首页重新抓取 / URL 重新提交**，迫使引擎重新读取 favicon。
  - Bing Webmaster → URL Submission / Crawl 提交 `https://www.tianyimachine.com/` 与 `https://www.tianyimachine.com/favicon.ico`。
  - Yandex Webmaster → Индексирование → Переобход（重新抓取）首页 URL。
- 已向用户说明此为抓取缓存问题，并给出详细操作步骤；无需 GitHub 提交（文件已在线）。

## 排查 Yandex Webmaster "Favicon file not found"
- 用户截图显示 Yandex Webmaster Diagnostics 提示 "Favicon file not found"。
- 实测结论：**favicon.ico 文件与线上响应均正常，不是部署/代码问题**。
  - 本地文件 `favicon.ico` 存在（34,345 字节）。
  - 线上 `https://www.tianyimachine.com/favicon.ico` 返回 HTTP 200，Content-Type `image/vnd.microsoft.icon`。
  - 首页 `<head>` 已正确声明 `<link rel="icon" href="/favicon.ico">`。
  - `robots.txt` 为 `Allow: /`，未阻止 favicon 抓取。
- 根因：Yandex 之前抓取首页时 favicon 尚未部署/未刷新，诊断报告基于历史抓取数据；Yandex 提示中也建议通过 "Rerender pages"（Переобход）提交首页以加速更新。
- 解决方向（无需改代码）：在 Yandex Webmaster 中点击 "Rerender pages" / "Переобход страниц" 重新提交首页 `https://www.tianyimachine.com/`，通常 3 天内刷新 favicon。
